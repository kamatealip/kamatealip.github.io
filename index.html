02 / Agentic AI workflow

From prompt to action, not just prompt to text.

The engineering pattern I use for agentic systems.

01

Understand

Parse the user's goal, constraints, context, and required output.

02

Plan

Break the request into a stateful sequence of tasks and decisions.

03

Retrieve

Bring in trusted context using RAG, search, databases, or APIs.

04

Use tools

Call external tools such as search, data, or application services.

05

Act

Generate the next action, structured result, or product-side change.

06

Validate

Check tool outputs, schemas, business rules, and failure paths.

07

Remember

Persist useful state so multi-turn workflows can continue reliably.
